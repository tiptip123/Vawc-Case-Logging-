🚀 VAWC SYSTEM — RELEASE CHECKLIST
==================================

Follow these steps every time you push a new version to GitHub to ensure the "Install Update" feature works perfectly for staff.

1. UPDATE VERSION
   - Open version.txt in the app root.
   - Increment the version number (e.g., from 1.0.0 to 1.1.0).

2. PREPARE MANIFEST
   - Update update_manifest.json in the app root.
   - Match the "version" to the one in version.txt.
   - Write a short "description" of what changed.
   - Ensure the "files" list includes EVERY file in the app (see Template below).

3. VERIFY FILE STRUCTURE
   - Ensure all new screens or utils are added to their respective folders.
   - Check that no sensitive files (like the local database file) are accidentally included in the manifest "files" list.

4. PUSH TO GITHUB
   - Commit and push all changes.

5. STAFF UPDATE PROCESS (The "Pro Tip" Way)
   - Staff downloads the "Source code (zip)" from the GitHub Release or Main branch.
   - Staff extracts the ZIP folder.
   - Staff opens VAWC App -> Settings -> Install Update.
   - Staff points the folder picker to the extracted folder (e.g., vawc-app-main).
   - DONE! ✅
