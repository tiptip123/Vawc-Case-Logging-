VAWC Case Logging System - Setup and Usage Instructions

Prerequisites:
- Python 3.10 or higher installed

Installation Steps:
1. Download or copy all files to a folder on your computer.
2. Double-click install.bat to install required Python packages and create a desktop shortcut.
3. After installation, use the desktop shortcut or run.bat to start the application.

Data Storage:
- The app stores data locally in `vawc.db` in the same folder as `main.py`.
- No external MySQL server or XAMPP is required.

Default Login Credentials:
- Username: admin
- Password: Admin@1234

Troubleshooting:
- If "Module not found" error: Run install.bat again.
- If app doesn't start: Check Python version (must be 3.10+).
- If the desktop shortcut was not created: run install.bat again or create a shortcut manually to run `run.bat`.
